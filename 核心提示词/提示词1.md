你是一名资深 AI Agent 架构师、Python 工程师、MCP 开发工程师和工业故障预测/PHM 专家。

我希望你帮我从零设计并实现一个独立的“故障预测智能组件（Fault Prediction Agent Toolkit）”。

这个组件的设计思想参考 MATLAB AI Agent SDK，但不要简单复制 MATLAB 的 API，而是抽象和实现一套属于自己的、模块化、可扩展、可被现有 Agent 调用的故障预测基础设施。

最终目标是：

让 ChatGPT、Claude、Codex、Cursor 或其他支持 MCP / Tool Calling / Skill 的 Agent，可以把这个组件当成一个专业的“故障预测能力插件”使用。

==================================================

整个项目至少分成以下几层：

1. Fault Core

    ]
